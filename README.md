# Customer Shopping Behavior Analysis

## 📊 Project Overview

This project analyzes customer shopping behavior using **Python, SQL, and Power BI** to understand purchasing patterns, customer preferences, sales performance, and factors influencing customer spending.

The project follows an end-to-end data analytics workflow:

**Data → Python → SQL → Power BI → Business Insights**

The goal is to transform raw customer shopping data into meaningful insights that can support business and marketing decisions.

---

## 🎯 Business Problem

Businesses need to understand their customers' purchasing behavior to improve sales, customer satisfaction, and marketing strategies.

This project aims to answer questions such as:

* Which product categories generate the most sales?
* What are the purchasing patterns of different customer groups?
* Which customers spend the most?
* How do discounts affect purchasing behavior?
* Which products and categories are most popular?
* How do customer characteristics influence shopping behavior?
* What insights can help businesses improve their sales strategy?

## 🔄 Project Workflow

### 1. Data Collection

The customer shopping behavior dataset was collected in CSV format and contains information related to customers, products, purchases, discounts, and shopping patterns.

### 2. Data Cleaning & Preparation

Python and Pandas were used to:

* Load the dataset
* Inspect the data
* Identify missing values
* Check duplicate records
* Examine data types
* Clean and transform the data
* Prepare the dataset for analysis

### 3. Exploratory Data Analysis

Exploratory Data Analysis was performed to identify trends and patterns in customer purchasing behavior.

The analysis included:

* Customer segmentation
* Product category analysis
* Purchase frequency
* Revenue analysis
* Discount analysis
* Customer demographic analysis
* Spending patterns

### 4. SQL Analysis

SQL was used to answer important business questions through queries involving:

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* `HAVING`
* Aggregate functions
* `CASE`
* `JOIN`
* Subqueries

The SQL analysis helped extract useful business insights from the cleaned dataset.

### 5. Power BI Dashboard

An interactive Power BI dashboard was created to visualize the key findings.

The dashboard provides insights into:

* Total sales/revenue
* Customer behavior
* Product categories
* Purchase trends
* Customer segments
* Discount usage
* Shopping patterns

Users can interact with the dashboard using filters and visualizations.

## 🚀 How to Run the Project

### Python Analysis

1. Clone or download this repository.
2. Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

3. Open:

```text
Customer_Shopping_Behavior_Analysis.ipynb
```

4. Run the notebook cells sequentially.

### SQL Analysis

Open:

```text
customer_behavior_sql_queries.sql
```

Run the queries in your preferred SQL database environment after importing the dataset.

### Power BI Dashboard

Open:

```text
customer_behavior_dashboard.pbix
```

using **Microsoft Power BI Desktop**.
